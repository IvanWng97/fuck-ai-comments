# Security policy

Security fixes are provided for the latest release line.

Please report vulnerabilities through GitHub's private vulnerability reporting
for `IvanWng97/fuck-ai-comments`. Do not open a public issue for an unpatched
vulnerability.

Release archives include SHA-256 checksums and GitHub build attestations. A
checksum detects changed bytes; an attestation additionally binds an artifact
to this repository and its build workflow. Neither is a substitute for
reviewing what the program does.
